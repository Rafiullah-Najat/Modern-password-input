# 🔐 Modern Password Input UI

A clean and modern **password input component** built using pure **HTML & CSS**. This project demonstrates a stylish UI design with soft shadows, glowing effects, and a neumorphism-inspired layout.

---

## ✨ Features

* 🔒 Elegant password input field
* 🎨 Neumorphism-inspired design
* 💡 Soft shadows and glow effects
* 🖱️ Interactive button with hover animation
* 📱 Fully responsive layout
* ⚡ No JavaScript required


---

## 📸 Preview

This UI includes:

* Rounded input field with dark theme
* Glowing text effect
* Circular button with lock icon
* Smooth shadow transitions
* Demo: https://rafiullah-najat.github.io/Modern-password-input/

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

  * CSS Variables

  * Box Shadows
  * Pseudo-elements (`::after`)

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/modern-password-input.git
```

2. Open the project folder:

```bash
cd modern-password-input
```

3. Run the project by opening `index.html` in your browser.

---

## 🎨 Customization

You can easily change the design by editing the CSS variables:

```css
:root {
  --first-color: hsl(20, 82%, 58%);
  --body-color: hsl(220, 2%, 62%);
  --container-color-dark: hsl(220, 4%, 34%);
}
```
